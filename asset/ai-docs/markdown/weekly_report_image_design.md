# 周报图片化处理思路（企业微信群缩略图可读版）

> 用途：`cbl_task_notification` 的内容逻辑完成后，按本文档把周报内容拆分、渲染成
> "缩略图即可读"的周报图片并发送到企业微信群。
> 参考实现（当前为测试模板）：`temp/test_send_report_image.py` 的 `page()` 函数。

---

## 1. 平台约束（为什么这样设计）

| 约束 | 数值/说明 |
|---|---|
| 群内缩略图显示宽度 | 客户端固定：PC 约 350px，手机约屏宽 60~70%，**与原图分辨率无关** |
| image 消息 | 群内直接展示大图的唯一类型，≤ 2MB |
| news/markdown 内嵌图 | 只显示小缩略图，不满足"不点开可读" |
| 可读性判据 | 缩略后文字 ≥ 约 13px（即 **源图字号 ≥ 图宽 × 3.7%**） |

结论：**画布 960×540（16:9 横图）+ 按下方字号规格**，缩放比 350/960 ≈ 0.36，
正文缩略后约 16px，可读。

## 2. 画布与字号规格（960×540）

| 元素 | 字号 | 缩略后 | 说明 |
|---|---|---|---|
| 顶栏标题 | 56px | ~20px | 深蓝底(24,61,119)白字，左标题右"本周概览" |
| 顶栏周期/来源 | 28px | ~10px | 辅助信息，允许小 |
| 指标数字 | **72px** | ~26px | 新增/关闭/遗留/按期率 4 块卡片，数字是第一视觉 |
| 指标标签 | 30px | ~11px | 卡片内小字 |
| 表格文字（含表头） | **44px** | ~16px | ≤4 列 × ≤4 行，超出一行文字用缩写 |
| 风险结论行 | 36px | ~13px | 一句话，浅橙底色块 |

配色：正文 (34,38,46)、次级 (128,138,152)、边线 (222,226,232)、隔行底 (246,248,250)、
正向 (36,130,90)、警示 (200,90,40)。

## 3. 内容准入规则（拆分的核心）

**进图**的只有三类"一眼可懂"的信息：

1. 指标数字：恰好 4 个（多了挤），标签 ≤ 5 个字
2. 表格：≤ 4 列，每格 ≤ 8 个字，行数 ≤ 4
3. 一句话结论/风险：≤ 24 个字

**不进图**的内容（文字超标的都算）→ 改走第二条消息：

- markdown 消息：一段摘要（新增/关闭/遗留 + 风险）+ `[查看完整周报](文档链接)`
- 或 file 消息发完整周报附件（≤5MB）

## 4. 接入 cbl_task_notification 的拆分步骤（内容逻辑完成后执行）

1. 在 `cbl_task_notification` 中定义周报数据结构（建议 dict）：
   ```python
   report = {
       "period": "2026-10-13 ~ 10-19",
       "metrics": [("新增", "26", 警示色), ("关闭", "31", 正常色),
                    ("遗留", "18", 中性色), ("按期率", "86%", 正常色)],
       "table": [("CBL_SIT", "9/12", "6", "正常"), ...],   # ≤4 行
       "risk": "一句话结论（≤24字）",
       "detail_url": "https://...",                        # 完整周报链接
   }
   ```
2. 把 `temp/test_send_report_image.py` 的 `page()` 迁入
   `cbl_task_notification`（建议独立函数 `render_weekly_report_image(report) -> 图片路径`），
   数据全部改为从 report 取
3. 发送组合：`send_image(图片)` + `send_markdown(摘要+detail_url 链接)` 两条一起发
4. 生成图片临时目录建议：`temp/report_images/`（运行日志已统一在 `temp/job_logs/`，30 天自动清理）

## 5. 若缩略效果仍不理想的调节旋钮

| 症状 | 旋钮 |
|---|---|
| 表格还是偏小 | 表格单独发一张（画布可降为 960×360，字号再加到 52px） |
| 想再大一档 | 画布降到 880×495，字号保持不变（等效再放大 ~9%） |
| 指标数字想更醒目 | 数字加到 88px，标签挪到数字下方 |
| 内容实在压缩不了 | 放弃图片承载细节：图只留 4 个指标数字 + 一句话结论，
  其余全部走 markdown/附件 |
