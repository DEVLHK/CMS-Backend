### 3.2 按钮

| 按钮 | 位置 | 行为 |
|---|---|---|
| 新增 | 非操作列 | 新增合同（需先上传合同获取信息） |
| 修改 | 操作列 | 按字段"修改"列的规则编辑 |
| 删除 | 操作列 | 直接删除记录，**需二次确认提示** |
| 开票明细 | 操作列 | 弹出：合同开票明细弹窗 |
| 收款明细 | 操作列 | 弹出：合同收款明细弹窗 |
| 作废 | 表里有生效/作废状态，点作废后状态为失效 | 二次确认？（见 Q6） |

### 3.3 查询条件和查询按钮（非操作列）

1. 支持查询：合同编号、企业名称、完成情况、月份、区域、项目类型、是否生效
2. 合同编号、企业名称支持模糊查询，**不区分大小写**
3. 月份可指定范围，默认当月，也可快捷指定当月
4. 操作列的按钮放到列表每一行中，增加一列操作列，**固定展示**，不因横向拖动而消失

## 8. 合同解析方案

### 8.1 样例（`20261030-1安预-茂名市信邦建材有限公司(1).doc`）

固定格式中可解析的字段及原文锚点：

| 回填字段 | 原文锚点 | 样例值 |
|---|---|---|
| 合同编号 | `合同编号：xxx`（文末页脚区） | `20261030-1安预XY` |
| 企业名称 | 首个 `甲方：xxx` | `茂名市信邦建材有限公司` |
| 联系人/联系方式 | 甲方段首个 `联系人：姓名+手机号` | `张义勇` / `18814289999` |
| 项目类型 | `项目类型：xxx`（第一条内） | `生产安全事故应急预案` |
| 合同金额 | `人民币…整（¥5000.00元整）`，取 `¥` 后数字 | `5000.00` |
| 签约日期 | `签订日期：YYYY年M月D日`（首个） | `2026-10-30` |
| 月份 | 由签约日期推导 `YYYY-MM` | `2026-10` |
| 区域 | （辅助）甲方地址含区域关键词时可预填，仍可修正 | `茂南区` |

### 8.2 解析流程

1. 前端先调 `uploadContract` 上传 .doc 文件 → 后端暂存并解析 → 返回上述预填字段（含暂存文件引用）
2. 用户修正字段后调 `addContract` 保存 → 后端落库并将文件从暂存区移动到 `temp/contracts/{合同编号}/contract.doc`
3. 解析失败/字段缺失：返回告警字段清单，前端留空由用户手填（合同上传仍必须成功，仅预填不完整）

### 8.3 Word 文本提取依赖（.doc 为二进制格式）

按优先级探测可执行文件，取第一个可用的：

| 优先级 | 工具 | 环境 |
|---|---|---|
| 1 | `antiword` | Linux 生产服务器（需安装） |
| 2 | `textutil` | macOS 开发机（系统自带） |
| 3 | `libreoffice --headless --convert-to txt` | 兜底 |

提取纯文本后按 8.1 的正则锚点解析，不依赖 python-docx（其只支持 .docx）。
